How the website works

Choose a CPU scheduling algorithm, enter the arrival times and burst times for each process, then select Solve. The website calculates the schedule and displays the results as a Gantt chart, a table of waiting and turnaround times, and a step-by-step solution. Priority algorithms also use the priority values you enter, while Round Robin uses the time quantum.
